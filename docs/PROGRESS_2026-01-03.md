### ✅ BE 27 Studio 虛擬試穿修復

**問題診斷**
- 試穿結果無法加入白板（只顯示一行字）
- 原因：`getImageUrl()` 不支援 base64 格式

**解決方案**
```typescript
// frontend/lib/api/django.ts
export function getImageUrl(imagePath: string | null): string {
  if (!imagePath) return '/images/placeholder.jpg'
  if (imagePath.startsWith('http')) return imagePath

  // 新增：支援 base64 格式
  if (imagePath.startsWith('data:image/')) return imagePath

  const baseUrl = process.env.NEXT_PUBLIC_DJANGO_MEDIA_URL || 'http://localhost:8000/media/'
  return `${baseUrl}${imagePath}`
}
```

### ✅ 兩步試穿功能實現

**功能說明**
- 圈選 1 件 → 單件試穿
- 圈選 2+ 件 → 兩步試穿（上衣 → 下身）

**實現邏輯**
```typescript
// frontend/app/studio/page.tsx
if (items.length === 1) {
  // 單件試穿
  const response = await fetch('/api/tryon', {
    body: JSON.stringify({
      personImageUrl: userPhoto,
      garmentImageUrl: garmentUrl,
      customRequest: '',
    })
  })
} else {
  // Step 1: 試穿上衣
  const topResult = await fetch('/api/tryon', {
    body: JSON.stringify({
      personImageUrl: userPhoto,
      garmentImageUrl: topUrl,
      customRequest: 'only top',
    })
  })

  // Step 2: 用上衣結果試穿下身
  const bottomResult = await fetch('/api/tryon', {
    body: JSON.stringify({
      personImageUrl: topResult.url,  // 使用上一步結果
      garmentImageUrl: bottomUrl,
      customRequest: 'only bottom',
    })
  })
}
```
